# Discord 伺服器設定步驟

> 這份文件教你做三件事：①建立自己的 Discord 伺服器、②建立給 agent 用的頻道並拿到 `CHANNEL_ID`、③產生邀請連結給同學。
> 做完之後，接著做 `docs/discord-bot-setup.md`。
>
> 說明：Discord 偶爾會改畫面文字。如果你看到的名稱跟這裡有一點不同，找意思相近的選項即可。括號裡的英文是英文介面的寫法。

名詞：

- **伺服器（Server）**：Discord 裡一個你自己的「社群空間」，裡面可以有很多聊天室。
- **頻道（Channel）**：伺服器裡的一個聊天室。這個專案只會用到其中一個。

---

## 事前準備

- 一個 Discord 帳號，並且已經登入。
- 建議用 **Discord 桌面版程式**（Windows 開始選單搜尋「Discord」）。用瀏覽器開 `https://discord.com/app` 也可以，步驟一樣。

---

## 一、建立你自己的伺服器

1. 打開 Discord。
2. 看畫面**最左邊**那一排圓形圖示，拉到最下面，找到一個 **綠色的「＋」**（滑鼠移上去會顯示「新增伺服器」／Add a Server），點它。
3. 跳出視窗，點 **「自己建立」**（Create My Own）。
4. 下一個畫面問你這個伺服器是做什麼的，點 **「供我和我的朋友使用」**（For me and my friends）。
5. 在「伺服器名稱」欄位輸入名稱，例如 `食物熱量測試`。圖示可以不用上傳。
6. 點右下角 **「建立」**（Create）。

做完後，畫面左邊會多一個你剛建的伺服器圖示，Discord 會自動帶你進去。

---

## 二、建立給 agent 用的頻道，並拿到 `CHANNEL_ID`

### 2-1. 建立頻道

1. 進入你剛建的伺服器。畫面**左邊第二欄**（比圖示欄寬一點）會有一個「文字頻道」（TEXT CHANNELS）區塊，裡面有一個預設的 `# 一般`（general）。
2. 把滑鼠移到「文字頻道」這幾個字上，右邊會出現一個 **「＋」**，點它。
3. 跳出「建立頻道」視窗：
   - 頻道類型選 **「文字」**（Text）。
   - 頻道名稱輸入 `食物照片`（Discord 可能會自動變成英文小寫加橫線，這沒關係）。
   - **「私人頻道」（Private Channel）先不要打開**。後面讓同學加入會比較簡單。
4. 點 **「建立頻道」**。

左邊頻道清單會多出 `# 食物照片`，點它進去，這就是 agent 要聽的頻道。

### 2-2. 打開「開發者模式」（為了複製頻道編號）

Discord 預設不會讓你複製頻道編號，要先打開一個開關。

1. 看畫面**左下角**，你的頭像和名字旁邊有一個 **齒輪圖示**（使用者設定），點它。
2. 左邊選單往下捲，找到 **「進階」**（Advanced），點它。
3. 把 **「開發者模式」**（Developer Mode）的開關打開（變成綠色）。
4. 按右上角的 **ESC**（或 X）離開設定。

> 這個開關只是多顯示幾個複製選項，不會有任何副作用。

### 2-3. 複製 `CHANNEL_ID`

1. 在左邊頻道清單裡，對 `# 食物照片` **按滑鼠右鍵**。
2. 在跳出的選單最下面，點 **「複製頻道 ID」**（Copy Channel ID）。
3. 現在這串數字已經在你的剪貼簿了。打開 Windows 的「記事本」，按 **Ctrl + V** 貼上，確認是一長串純數字，大約 17 到 20 位，例如 `123456789012345678`。
4. 先留在記事本裡，等一下設定 `.env` 時會用到。

> `CHANNEL_ID` 不是密碼，外洩的風險不高，但沒必要公開貼出去。

---

## 三、產生邀請連結，讓同學加入

> 提醒：加入你伺服器的人，都可以在 `# 食物照片` 傳照片，**每一張都會用到你自己的 Claude 額度**（架構文件第 13 節）。所以只邀請你信任的同學，不要把連結貼到公開的地方。

1. 在畫面**左上角**，點你的**伺服器名稱**（例如 `食物熱量測試`），會展開一個選單。
2. 點 **「邀請夥伴」**（Invite People）。
3. 跳出視窗的最下面有一行邀請連結，旁邊有個小齒輪 **「編輯邀請連結」**（Edit invite link），點它。
4. 設定兩個選項：
   - **「到期時間」**（Expire After）：選 **7 天**。測完就自然失效，比較安全。
   - **「使用次數上限」**（Max Number of Uses）：選你同組同學的人數，或選 **10 次**。
5. 點 **「產生新連結」**（Generate a New Link）。
6. 點 **「複製」**（Copy），把連結貼到你和同組同學的聊天群組。
7. 同學點連結後，Discord 會請他按「接受邀請」（Accept Invite），他就進到你的伺服器了。

### 確認同學進來了

在畫面**右邊**有「成員清單」（如果沒看到，點右上角的「顯示成員名單」圖示）。同學加入後，名字會出現在這裡。

### 想取消邀請連結

回到「邀請夥伴」視窗，或到「伺服器名稱」→「伺服器設定」→「邀請」，找到那條連結，按右邊的 X 刪除，它就立刻失效。

---

## 做完後的檢查

- [ ] 左邊有你的伺服器，裡面有 `# 食物照片` 頻道。
- [ ] 記事本裡有 `CHANNEL_ID`（一長串純數字）。
- [ ] 同學能用邀請連結加入，且在成員清單看得到。
- [ ] 邀請連結沒有貼在公開的地方。
